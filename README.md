# 事件视界 · The Event Horizon

实时史瓦西黑洞模拟 —— 单文件 WebGL,零依赖。

**在线体验 → https://wangbh030722.github.io/blackhole-sim/**

每一帧对每个像素的光子做零测地线数值积分(220 步),呈现:

- **引力透镜** — 吸积盘背面被时空曲率弯折到阴影上下方
- **多普勒聚束** — 盘面接近侧增亮蓝移,远离侧黯淡红移
- **光子环** — 1.5 R_s 处绕行多周才逃逸的光,形成阴影边缘的锐利细环
- **引力红移**、开普勒差速旋转的湍流盘面、程序化星空

## 交互

| 操作 | 效果 |
|---|---|
| 拖拽 | 旋转视角 |
| 滚轮 | 推近 / 拉远 (6.5–38 R_s) |
| 滑杆 | 观测倾角 · 吸积盘辐射 · 时间流速 |
| HALF-RES | 半采样渲染(移动端自动开启) |

## 本地运行

```bash
python3 -m http.server 8742
# 打开 http://localhost:8742
```

纯静态单 HTML,无构建步骤。
